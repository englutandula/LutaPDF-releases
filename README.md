# LutaPDF downloads

Developed by **Eng.Luta**.

This repository holds the official LutaPDF release binaries and installer packages.

## Download the latest version

| Platform | File |
|---|---|
| Windows 10/11 (x64), installer | [LutaPDF-windows-x64.msi](https://github.com/englutandula/LutaPDF-releases/releases/latest/download/LutaPDF-windows-x64.msi) |
| Windows (x64), portable | [LutaPDF-windows-x64-portable.zip](https://github.com/englutandula/LutaPDF-releases/releases/latest/download/LutaPDF-windows-x64-portable.zip) |
| macOS (Intel and Apple Silicon) | [LutaPDF-macos-universal.dmg](https://github.com/englutandula/LutaPDF-releases/releases/latest/download/LutaPDF-macos-universal.dmg) |
| Linux: Debian, Ubuntu | [LutaPDF-linux-x86_64.deb](https://github.com/englutandula/LutaPDF-releases/releases/latest/download/LutaPDF-linux-x86_64.deb) |
| Linux: Fedora, openSUSE, RHEL | [LutaPDF-linux-x86_64.rpm](https://github.com/englutandula/LutaPDF-releases/releases/latest/download/LutaPDF-linux-x86_64.rpm) |
| Linux, any distribution (tarball) | [LutaPDF-linux-x86_64.tar.gz](https://github.com/englutandula/LutaPDF-releases/releases/latest/download/LutaPDF-linux-x86_64.tar.gz) |

Every release also includes the command-line tool (`LutaPDF-cli-*`) and a `SHA256SUMS.txt` file
for checking your download.

All versions: [Releases](https://github.com/englutandula/LutaPDF-releases/releases)

## First launch

- **macOS:** the app is not notarized yet. Right-click LutaPDF.app ▸ **Open**, then confirm.
- **Windows:** if SmartScreen shows "Windows protected your PC", click **More info ▸ Run anyway**.
